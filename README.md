# 🩺 Geospatial AI-Based Pneumonia Detection

## 📌 Project Overview

This project focuses on AI-based pneumonia detection combined with geospatial analysis to visualize disease distribution and identify potential geographical hotspots.

It integrates deep learning, explainable AI, and geospatial visualization to support healthcare monitoring and disease analysis.

## 🎯 Key Objectives

- Develop an AI-based pneumonia detection approach.
- Apply deep learning techniques for medical image classification.
- Use explainable AI techniques to understand model predictions.
- Visualize geographical disease patterns and hotspots.
- Provide an interactive dashboard for geospatial monitoring.

## 🧠 Technologies Used

- Python
- Deep Learning
- Custom CNN
- MobileNetV2-CBAM
- Grad-CAM
- Geospatial Analysis
- HTML, CSS and JavaScript
- Jupyter Notebook
